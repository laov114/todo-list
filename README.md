# 待办事项清单

一个简洁美观的待办事项Web应用，帮助你轻松管理日常任务。

## 功能特点

- 添加新的待办事项
- 标记任务为已完成
- 删除不需要的任务
- 数据本地存储，刷新页面不会丢失
- 响应式设计，支持移动端

## 技术栈

- HTML5
- CSS3
- JavaScript（原生）
- localStorage（本地数据存储）

## 使用方法

1. 在输入框中输入新的任务
2. 点击"添加"按钮或按回车键添加任务
3. 点击复选框标记任务完成状态
4. 点击删除按钮移除任务

## 本地运行

1. 克隆仓库到本地
```bash
git clone https://github.com/laov114/todo-list.git
```

2. 使用浏览器打开 index.html 文件即可运行
